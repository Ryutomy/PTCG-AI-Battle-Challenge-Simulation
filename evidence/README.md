# Evidence

公開実績を裏付ける画像や、現在再実行した監査結果を配置します。

- [提出アーカイブ監査記録](submission-manifest.md)

追加予定:

- 最終Leaderboardで590位を確認できる画像
- Bronze Medalを確認できるKaggleプロフィールまたは結果画面
- 必要に応じてKaggle submission履歴

## Evidence Rules

- アカウント情報など不要な個人情報はマスクする
- 画像の取得日と出典URLを記録する
- 当時の記録と現在再検証した結果を区別する
- ローカル監査の一時出力は`local-audit/`へ置き、Gitには含めない
